# Domain Glossary

- **Site Config** (`utils/site.ts`) — single source of truth for site-wide facts: URL, brand strings, contact details, external links, and the Page Entries. Nothing hardcodes an email, resume URL or nav item outside this module.
- **Page Entry** (`PAGES` in `utils/site.ts`) — one static page's identity: path, nav label, title, description, OG card copy and sitemap settings. `NAV_LINKS`, `pageMetadata(key)`, `pageOgImage(key)` and the sitemap all derive from it; each route's `opengraph-image.tsx` / `twitter-image.tsx` stays only because Next requires the file. `test/pages.test.ts` fails if a static route has no entry.
- **Page Metadata** (`utils/metadata.ts`) — `buildMetadata()` owns the OpenGraph/Twitter scaffold every page shares (the root layout spreads it too); `deriveSeo()` owns the portfolio title/description/URL/publish-date derivation; the JSON-LD builders (`personJsonLd`, `websiteJsonLd`, `articleJsonLd`, `breadcrumbJsonLd`) own the structured-data story. Case-study SEO is assembled by the Case Study loader so this module stays import-safe for tests.
- **Contentful Source** (`utils/contentful/source.ts`) — the adapter seam for everything fetched from Contentful: `query()` (GraphQL) and `fetchAsset()` (blur placeholders). `graphqlSource` is the production adapter; tests use `fixtureSource` (`test/stubs/contentfulSource.ts`) keyed by the query constants in `utils/contentful/queries.ts`. Uncached loaders (`utils/contentful/loaders.ts`) take a source and own all raw→domain shaping; the cached accessors (`utils/contentful/index.ts`) only add `"use cache"` and bind `graphqlSource`, since `cacheLife()` can't run outside App Router rendering.
- **Case Study** (`loadCaseStudy` in `utils/contentful/loaders.ts`, cached as `getCaseStudy(slug)`) — everything one portfolio page needs: the enriched item, its SEO (incl. OG image from the first Image block) and the prev/next pager, which cycles through the featured order (fetched via a slug+title-only query). Non-featured items, or a featured list of one, get no pager. Page and `generateMetadata` share the one cached call.
- **Image Intent** (`utils/imageParams.ts`, `utils/contentfulImage.ts`) — per-intent transform preset (`hero`, `card`, `og`, `poster`, `twoColumn`) with a per-intent blur opt-in, applied to a Contentful image URL server-side. The custom loader (`utils/contentfulLoader.ts`) owns the final URL the browser fetches: it rewrites width/quality/format per srcset entry, scaling any baked-in crop proportionally, so Contentful's CDN serves the final AVIF with no second encode.
- **Image Variant** (`components/ImageWrapper.tsx`) — rendering preset (`card`, `hero`, `twoColumn`) that owns `sizes`, fill mode and the positioning context for its own gradient overlay. Callers pick a variant; they never pass raw `next/image` props.
- **Card Layout** (`utils/cardLayout.ts`) — `cardLayout(grid, index, count)` returns a card's slot (size, Image Variant, priority, showDescription) for the `featured` or `footer` grid. Cards render the size as `card--large` / `card--full`; CSS never infers layout from position.
- **Block** (`blocks/`, `types/contentful.ts`) — a discriminated-union Contentful content section (`TextLeft`, `TextArea`, `Image`, `Video`, `TwoColumn`).
- **Block Registry** (`blocks/registry.tsx`) — per-Block co-location of GraphQL fragment, enricher and renderer, exported from each `blocks/<Name>/index.tsx`. The portfolio query composes `BLOCKS_FRAGMENT` from it and `blocks/index.tsx` dispatches through it; adding a union member fails typecheck until registered.
- **Icon Palette** (`utils/visuals.tsx`) — `visualFor(title, context)` deterministically assigns an icon plus `{bg, color}` per title; the palette, hashing and the per-context icon sets are implementation details.
